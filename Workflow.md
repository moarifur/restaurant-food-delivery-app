# 🍽️ Restaurant Food Delivery App

A full-stack responsive restaurant food ordering web application inspired by Lama Dev's YouTube tutorials. This project is built using Next.js, Tailwind CSS, JavaScript, Prisma, PostgreSQL, Stripe, and more.

---

### 🎨 UI Design => EPIC-UI-DESIGN - UI/UX Design

> Complete the frontend design using Tailwind + Next.js

### Stories

- `UI-001`: Setup Next.js project with TypeScript and Tailwind
- `UI-002`: Create basic layout and navigation
- `UI-003`: Build responsive homepage with hero slider
- `UI-004`: Create featured product section
- `UI-005`: Add offers and category display
- `UI-006`: Design product list and single product pages
- `UI-007`: Implement cart UI and quantity logic
- `UI-008`: Build responsive login and orders page
